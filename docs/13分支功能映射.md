# 哒哒 Agent 十三分支功能映射

## 分支定义

| 分支 | 流程图功能 | 主要依赖 | 初测状态 | 回归重点 |
| --- | --- | --- | --- | --- |
| a | 新建提醒 | 1.7B 路由、9B 槽位抽取、确认态、task 写库、schedule 物化 | 失败 | 确认后只提交一次，返回 task_id 和 schedule_id |
| b | 删除或修改提醒 | 提醒查询、目标消歧、task 更新、schedule 重建或取消 | 失败 | 查询为空必须失败；禁止虚假成功 |
| c | 查询提醒 | task 与 schedule 活跃列表、结果注入 9B | 上游阻断 | a 修复后验证新增即查、断线重连和过期过滤 |
| d | 新增删除修改记忆 | 关键词抽取、画像或记忆表写入、确认态 | 失败 | 确认后返回 memory_id，重复确认不得重复写 |
| e | 查询记忆 | 关键词扩展、画像和记忆表检索、结果注入 9B | 上游阻断 | 同义表达、仅语义无编号、跨会话召回 |
| f | 调整音量 | 当前值读取、相对或绝对参数解析、设备下发、状态回读 | 失败 | 边界 0 和 100，模糊调高调低，幂等回读 |
| g | 调整亮度 | 当前值读取、相对或绝对参数解析、设备下发、状态回读 | 失败 | 未给具体值时采用明确步长，回读不得保持原值 |
| h | 查询天气 | 地点和日期抽取、天气服务、回复生成 | 正常 | 无地点、跨城市、超出预报范围和服务失败 |
| i | 再见 | 固定话术或短回复 | 正常 | 避免误触发会话清理或业务取消 |
| j | 产品功能查询 | 产品知识库或产品状态查询 | 待专项验证 | 流程图标注仅有框架，需确认可用数据源 |
| k | 晚安 | 固定话术或短回复 | 正常 | 与提醒创建复合意图的优先级 |
| l | 查询时间日历农历宜忌 | 时区、日历和农历服务 | 正常 | 跨时区、午夜、闰年、农历边界 |
| m | 闲聊或其他意图 | 9B 回复、时效性判断、联网 API LLM | 失败 | 最近、今天、当前等问题必须联网并提供来源 |

## 流程图标注问题

原流程图把“查时间 农历 宜忌”也标记为 `i`，导致字母映射中缺少 `l`。本仓库按 13 个互斥分支将该能力记为 `l`。研发应同步修正流程图、路由提示词、枚举定义和日志字段，避免测试口径不一致。

## 共用机制

- M1：1.7B 模型输出 a 至 m 单字符并以 `top1 > 0.9805` 作为高置信判定。
- M2：业务槽位校验与错误回喂，超预算后升级。
- M3：9B 工具复判、错误信息回喂循环与 API 模型兜底。
- M4：模型空响应只允许原样重试一次，仍为空时返回固定失败话术。
- M5：TTS 或确认话术播出前的用户打断，流程图标注为未实现。
- M6：夜间任务，包含软删除清理和日程补货，流程图标注为未实现。
- M7：短期上下文，用户静默两分钟后清空。
- M8：提醒触发扫描器，流程图标注为已实现。
- M9：提醒规则物化为未来七天具体日程，流程图标注为已实现。
