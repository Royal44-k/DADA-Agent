## 结果的使用口径

音量/亮度核心测试为 152 例、重复 3 轮，共 456 次，455 次全部通过（99.78%）；独立模糊边界测试的安全弃答表现仍有不足，详见原报告。

有状态路由 v2 首次完整运行 1278/1300（98.31%）；两条基础设施失败各重试一次后为 1280/1300（98.46%）。之后按用户确认修订标签，复用同一批模型输出可重算为 1283/1300（98.69%）。本轮没有 v3 的服务器重测记录。

最后指定的五项决定中，`b-02115 → m`、`d-00495 → m`、`l-01230 → m` 实际改变了标签；`j-02646 → a`、`m-01365 → l` 在 v2 中已经符合。因此相同输出下正确数增加 3 条。

各轮的标签、文本、对话状态和重试条件不同，具体限制见[历史结果说明](RESULTS_AND_CAVEATS.md)。这些被反复审校和调试使用的样本适合作为回归测试集；若要估计新的线上泛化准确率，应另用独立留出集。

## 资产范围

源资产共 132 份：15 份 HTML、51 份 Python、29 份 JSONL，以及日志、补丁、审校和汇总文件。现有 `Technique` 仓库还包含其他测试文档与架构研究专题，按原目录保留；本页与本轮 ZIP 的统计只涵盖本轮会话资产。

最初的全量 raw、部分早期地址/记忆/闲聊 API 专项报告、M2 Markdown/飞书导出及生产依赖副本当前缺失，详见[归档范围](ARCHIVE_SCOPE.md)。服务器连接指南和密钥不进入资产包。

## 完整性与复现

完整包可用 Python 3.10+ 在解压目录执行 `python tools/verify_archive.py`，核验已有文件哈希、JSONL 结构和历史结果计数。它不调用服务器。最终测试集还逐条核对了 v3 的八个导出字段及各分支顺序，见 [TESTSET_1300.md](TESTSET_1300.md)。

HTML 实验报告可下载后在浏览器打开；原流程图依赖 diagrams.net 在线查看脚本。服务器重新运行需要的生产代码、模型与数据库条件见[复现说明](REPRODUCIBILITY.md)。
